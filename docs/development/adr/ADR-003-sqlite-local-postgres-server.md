# ADR-003. SQLite локально / PostgreSQL на сервере

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

Нужна нулевая настройка для локального просмотровщика и масштабируемый
серверный режим для сайта/Android. Разные БД ≠ разные модели данных.

## Решение

Один слой SQLAlchemy 2 async + Alembic-миграции; `PRICESCOPE_MODE=local` →
SQLite (`data/pricescope.db`), `server` → PostgreSQL 16 (позже pgvector).
Типы — generic, без dialect-specific ENUM. Даты — UTC; SQLite — ISO-8601.

## Последствия

+ Один код роутеров/сервисов в обоих режимах.
+ Локальный запуск без внешних сервисов.
− Различия диалектов нужно учитывать в миграциях и индексах; тесты — на SQLite.
