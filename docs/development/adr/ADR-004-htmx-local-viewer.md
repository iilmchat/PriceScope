# ADR-004. HTMX + Jinja2 для локального viewer

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

Локальный просмотровщик должен работать офлайн, без Node.js-сборки, и
переиспользовать тот же API, что Flutter.

## Решение

Jinja2-шаблоны + HTMX-фрагменты (`/viewer/fragments/...`), JS/CSS лежат
локально в `apps/viewer/static/`. Alpine.js — только для мелких UI-состояний.
Никакого SPA-билда в локальном режиме.

## Последствия

+ `pip install` → `pricescope serve --local` → готово; работает без интернета.
+ Общий API с мобильным клиентом.
− Менее «богатый» UX, чем SPA; сложные виджеты (графики) — простые SVG/таблицы.
