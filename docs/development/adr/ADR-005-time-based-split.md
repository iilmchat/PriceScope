# ADR-005. Time-based split датасетов

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

Цены и товары меняются со временем. Случайный split приводит к утечке:
модель видит «будущие» цены при обучении и завышает метрики.

## Решение

Экспорт делится по времени: train — старые observation, val/test — более
новые; границы фиксируются в `manifest.json` (`split_boundaries`). Проверка:
`test.observed_at > train.observed_at`.

## Последствия

+ Честная оценка моделей, воспроизводимость экспериментов.
+ Манифест содержит версии парсеров/моделей и checksum.
− Требуется достаточно длинная история; их725 для новых категорий training-выборка может быть малой.
