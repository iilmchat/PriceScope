# ADR-006. CAPTCHA — остановка, обход запрещён

**Статус:** Accepted · **Дата:** 2026-11-24

## Контекст

Пятёрочка защищена антибот-системой. В наследуемом коде уже реализована
диагностика CAPTCHA без попыток её решить — это корректная, легальная позиция.

## Решение

При обнаружении маркеров CAPTCHA/антибота адаптер бросает
`CaptchaDetectedError`; `ParseRun.status=failed`, `error_code=CAPTCHA_DETECTED`,
сохраняется диагностика (title/url/markers/snippet), оператору — сообщение
«не запускайте повторно до восстановления доступа». Запрещены обход капчи,
подмена UA/IP ради обхода, фермы капчи и увеличение частоты запросов.

## Последствия

+ Юридическая и репутационная безопасность; соответствие ToS.
+ Единая диагностика вместо «тихого» пустого результата.
− Поток данных из Пятёрочки может прерываться; альтернативы — официальный API
  или ручной импорт CSV (легальные каналы).
