## (5) Что не так

- Карточка товара ищет по `external_id` + `store_code`: канонические `Product`
  появятся только в S07, поэтому ссылка «Сравнить» передаёт название в `query`.
- График — серверный SVG без интерактивных подсказок; достаточно для MVP.
- Фото товаров показываются по внешним CDN-ссылкам Ленты (офлайн-кэш фото — S07/S08).
- HTMX — облегчённая локальная реализация; полный vendor-HTMX планируется позже.

## (7) Обоснование

Все экраны работают через тот же REST API, что и Flutter-клиент: бизнес-логики
во viewer нет, только рендер. Делегирование событий в `htmx-lite.js` позволяет
фрагментам обновляться без перепривязки обработчиков. SVG-график генерируется
на сервере — просмотровщик остаётся полностью офлайн и не требует Node.js/CDN.
