## § 1. Как пользоваться

Автотесты (pytest, Flutter test) проверяют код, но **не** проверяют UX,
реальный импорт, сравнение и экспорт end-to-end. Этот чек-лист — для ручной
приёмки релиза.

Формат сценария:

| # | Действие | Ожидание | Статус | Комментарий |
|:---:|---|---|:---:|---|

**Статус:** `OK` / `FAIL` / `SKIP` / `N/A`.
**Дефект →** запись `PL-XXX` в [KNOWN_ISSUES.md](../KNOWN_ISSUES.md) (RULES § 1.13),
в комментарии — `trace_id` из API.

## § 3. Full regression

### § 3.1. Парсеры
- [ ] Лента: hub → categories → items → detail (фото), пагинация 50.
- [ ] Фикстуры с пустой категорией / битым JSON / таймаутом → skipped, не падение.
- [ ] Retry 3 попытки с backoff; circuit breaker после 5 ошибок; отмена — корректно.
- [ ] Raw snapshot сохраняется и имеет корректный sha256.

### § 3.2. API и БД
- [ ] Все endpoints из README § «API» отвечают по контракту; ошибка — единый envelope.
- [ ] Пагинация `page_size ≤ 200`, `total` корректен.
- [ ] Идемпотентный импорт по `idempotency_key` — повтор не создаёт второй ParseRun.
- [ ] Alembic upgrade/downgrade на копии БД.
- [ ] В БД нет дублей по `uq_observation`.

### § 3.3. Viewer
- [ ] Все 7 разделов открываются, пустые состояния понятны.
- [ ] HTMX-фрагменты обновляются без перезагрузки страницы.
- [ ] Фото загружаются из `data/photos/`, при отсутствии — placeholder.
- [ ] RU/EN (если включено в v0.1) не ломает вёрстку.

### § 3.4. Flutter
- [ ] Поиск, карточка, график, сравнение, избранное, настройки.
- [ ] Ошибка сети → понятное сообщение + trace_id.
- [ ] Офлайн-кэш (drift) сохраняет избранное после перезапуска.
- [ ] Сборки `flutter build web` и `flutter build apk --debug`.

### § 3.5. Данные/ML
- [ ] Time-based split: test-строки новее train.
- [ ] Checksums совпадают, manifest читается.
- [ ] Нет PII в JSONL; источник (raw_ref) есть.

---

## § 4. UI/UX
- [ ] Таблица не «прыгает» при фильтрации; есть понятное пустое состояние.
- [ ] Кнопки имеют понятные подписи; модалки закрываются Esc.
- [ ] На телефоне (Android) элементы не наезжают, текст читаем.

---

## § 5. Что НЕ покрыто автотестами (проверять вручную)

1. Реальный сетевой вызов Ленты и изменения её API.
2. Поведение Пятёрочки при CAPTCHA/блокировке.
3. Визуальное качество графиков и фото.
4. Производительность на большом объёме observation (≥ 100k).
5. Юридическая корректность использования данных (ToS).
