## Локальный просмотровщик

Запуск (из корня проекта):

```powershell
pricescope init-db
pricescope parse --store lenta --lat 55.3925 --lon 36.7323
pricescope serve --local
```

Откройте `http://127.0.0.1:8765`. Доступны разделы:

| Раздел | Что делать |
| :--- | :--- |
| **Обзор** | посмотреть статус последнего импора, число товаров/наблюдений, кнопка «Запустить импорт» |
| **Товары** | искать по названию, фильтровать по магазину и категории, сортировать по цене/дате, листать |
| **Карточка товара** | фото, атрибуты (вес/объём), цена по дням, ссылка на источник |
| **Сравнение** | выбрать товар и точку (lat/lon) — таблица цен по магазинам и «где дешевле» |
| **Импорты** | журнал запусков: статус, счётчики, ошибки, trace_id |
| **Совпадения** | подтвердить или отклонить связь «товар Ленты ↔ товар Пятёрочки» |
| **Настройки** | координаты, канал/бренд, лимиты запросов, retention raw-снапшотов |

Советы:
- поиск срабатывает с задержкой 250 мс — не нужно нажимать Enter;
- в карточке можно переключить период истории: 7 / 30 / 90 дней;
- цена всегда указана в рублях, но внутри системы хранится в копейках —
  округление происходит только при показе.

## Сравнение цен

1. Откройте **Сравнение**.
2. Введите название товара или выберите из поиска.
3. Укажите координаты точки (по умолчанию — из настроек).
4. Результат — строка на каждый магазин: цена, цена за кг/литр (если известна
   фасовка), дата наблюдения, ссылка на товар.
5. Самый дешёвый вариант помечен; разница в процентах показана относительно
   него.

> Если по товару есть только один магазин — comparison покажет одну строку и
> пометку «нет данных для сравнения». Запустите парсер второго магазина.

## История цен

Каждая зафиксированная цена — отдельная неизменяемая запись (`Observation`).
Повторный запуск парсера **не дублирует** запись за тот же день, а обновляет её
при изменении цены. В карточке товара history показывает:

- дату и время (UTC, показ локального времени браузера), • цену и старую цену,
- магазин и точку, • признак акции, • источник (raw snapshot).

## Импорты

Раздел **Импорты** — журнал `ParseRun`:

| Статус | Meaning |
| :--- | :--- |
| `pending` | задача создана |
| `running` | парсер работает |
| `success` | все товары обработаны |
| `partial` | часть карточек пропущена (есть `skipped`) |
| `failed` | фатальная ошибка (сеть, смена схемы, CAPTCHA) |
| `cancelled` | остановлено пользователем |

При `failed` откройте запись — там `error_code`, сообщение и `trace_id`.
Для Пятёрочки типичная причина — CAPTCHA: **не запускайте повторно сразу**,
дождитесь восстановления обычного доступа или используйте ручной импорт CSV.

## Совпадения товаров

Чтобы сравнить цены, система должна понять, что «Дезодорант РЕКСОНА 100мл»
из Ленты и «Рексона спрей 100 мл» из Пятёрочки — один товар.

- Совпадения с confidence ≥ 0.90 создаются автоматически.
- 0.70…0.90 попадают в очередь **Совпадения**: рядом два названия, фото,
  вес/объём и оценка. Кнопки «Один товар» / «Разные товары».
- Решение сохраняется и используется и для сравнения, и как разметка датасета.

## Экспорт датасета

```powershell
pricescope export --name product-matching --version 1
```

Результат в `datasets/exports/product-matching-v1/`: `train.jsonl`, `val.jsonl`,
`test.jsonl`, `manifest.json`, `checksums.sha256`. Разделение по времени:
обучение — на старых данных, валидация/тест — на новых. Персональные данные
не экспортируются.

## Flutter-клиент (веб + Android)

Разработчиком задаётся адрес API через `--dart-define`:

```powershell
cd apps/mobile
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://127.0.0.1:8765
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:8765
```

Экраны: поиск, карточка с графиком цен, сравнение, избранное ( хранится
локально), настройки адреса API. Для Android в доверенной сети используется
IP компьютера; для INTERNET permission и cleartext — dev-flavor конфиг.

## Частые вопросы

**Почему цена отличается от ценника?** Цена привязана к магазину/точке и времени
наблюдения; проверьте дату в карточке и координаты в настройках.

**Парсер Пятёрочки не запускается?** См. раздел «Импорты» — очень вероятно, CAPTCHA
или не задан `CAMOUFOX_EXECUTABLE_PATH`. Обход проверок запрещён.

**Куда сообщить об ошибке?** В [KNOWN_ISSUES.md](../KNOWN_ISSUES.md) с номером `PL-XXX`
или в GitHub Issues, приложив `trace_id` из ответа API.
